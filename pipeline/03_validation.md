# 生物学验证

## 1. 验证思路

用 N53-2（QT2）的 H3K27ac 和 H3K27me3 ChIP-seq 数据，验证模型预测的互作锚点是否富集在特定的染色质区域上。

- H3K27ac：活跃的增强子和启动子标记
- H3K27me3：抑制性染色质标记

## 2. 提取预测为互作的锚点

用训练好的模型对全部 309,618 个样本预测，提取概率 > 0.5 的样本（150,932 个），得到 301,864 个锚点。

## 3. ChIP-seq peak 合并

- H3K27ac：两个重复合并后 35,334 个 peak
- H3K27me3：两个重复合并后 25,196 个 peak

## 4. 富集分析

用 bedtools intersect 计算预测锚点和 ChIP-seq peak 的重叠率，并与随机背景对比。

| 标记 | 预测锚点重叠 | 随机背景重叠 | 富集倍数 | p-value |
|:---|:---|:---|:---|:---|
| H3K27ac（活跃） | 32.0% | 24.3% | 1.32 | < 0.001 |
| H3K27me3（抑制） | 23.6% | 14.1% | 1.67 | < 0.001 |

## 5. 结论

预测为互作的锚点显著富集在 H3K27ac 和 H3K27me3 区域上，说明：

1. 模型学到了有生物学意义的互作特征，不是随机噪声。
2. 模型能捕捉活跃和抑制两种类型的互作。
3. 这为后续用模型预测全基因组互作网络提供了可信度。

### 关于 H3K27me3 富集倍数更高的解释

H3K27me3 的富集倍数（1.67）高于 H3K27ac（1.32），原因有三：

1. 正样本来自 Hi-C 检测到的所有互作，不区分类型，既包含活跃互作（富集 H3K27ac），也包含 Polycomb 介导的抑制性互作（富集 H3K27me3）。
2. H3K27me3 是 broadPeak（平均几十 kb），H3K27ac 是 narrowPeak（平均 1-2 kb），peak 越宽，随机背景落在它上面的概率越低，富集倍数被放大。
3. 随机背景来自 OCR 区域，天然富集 H3K27ac，所以 H3K27ac 的随机背景重叠率（24.3%）本身就比 H3K27me3（14.1%）高。

这一结果说明模型学到了通用互作特征，而不是只学“活跃互作”。
