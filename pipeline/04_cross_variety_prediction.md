# 跨品种预测（QT653 / Ken-C8）

## 1. 数据准备

- OCR 区域：合并 LO-1/2/3 的 ATAC-seq peak，得到 89,895 个 OCR
- Hi-C 互作：从 QT653 的 cis_interaction.annotation.txt 提取 163,267 个互作对
- 锚点落在 OCR 上：anchor1 81.1%，anchor2 80.8%
- 序列提取：保留 154,051 个（过滤 5.6%）

## 2. 预测方法

直接用 QT2（N53-2）训练好的模型，对 QT653 的 154,051 个真实互作做预测。

注意：两个品种使用同一参考基因组 YouCai.fa，坐标系统一致。

## 3. 预测结果

| 指标 | 数值 |
|:---|:---|
| QT653 真实互作对数 | 154,051 |
| 预测为互作（概率 > 0.5） | 148,086 |
| 预测为互作（概率 > 0.9） | 146,503 |
| **召回率** | **96.13%** |
| 预测概率均值 | 0.9606 |
| 预测概率中位数 | 1.0 |

## 4. 与 QT2 对比

| 品种 | 召回率 |
|:---|:---|
| QT2（测试集） | 97.55% |
| QT653（全量） | 96.13% |

**差距只有 1.4 个百分点**，说明模型有很强的跨品种泛化能力。

## 5. 结论

- 在 QT2 上训练的模型，直接应用到 QT653，召回率仍达到 96.13%。
- 说明 QT2 和 QT653 的互作模式有很强的共性，模型学到了保守的互作序列特征。
- 这为模型在油菜其他品种上的应用提供了可信度。
